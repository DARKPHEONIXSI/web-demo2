ISU Judging System — Handbooks & Evaluation Criteria

How the ISU Judging System works: Each element receives a base value plus a Grade of Execution (GOE) on a scale of -5 to +5. Three Program Components (Composition, Presentation, Skating Skills) are scored from 0.25 to 10. A panel of up to 9 Judges provide trimmed-mean scores. The Technical Panel (Controller + 2 Specialists) identifies and calls elements independently.
