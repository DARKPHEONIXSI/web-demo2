⛸ On Ice - Skating Blog

This is a dynamic web application built with Python and Flask.

Because it requires a Python server and a database to run, it cannot be hosted directly on GitHub Pages (which only supports static HTML files).

To view the full website, you need to run it locally on your computer using the following commands in your terminal:

cd "path/to/simar"
python app.py

(Once running, open your browser and go to http://localhost:5000)
